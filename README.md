# 📚 NoteShare – Student Notes Sharing Platform

## 📌 Overview

**NoteShare** is a web-based application developed to help students upload, manage, and download academic notes securely. The platform provides an easy-to-use interface for sharing study materials while ensuring secure user authentication and efficient database management.

---

## 🚀 Features

* 👤 User Registration and Login
* 🔐 Secure User Authentication
* 📤 Upload Study Notes
* 📥 Download Notes
* 📝 Manage Uploaded Notes
* 👨‍💼 Admin Panel for Managing Users and Notes
* 🔍 Search and Browse Notes
* 📱 Responsive User Interface

## ⚙️ Installation

1. Clone the repository.
2. Move the project to your `laragon/www` directory.
3. Import the SQL database into MySQL.
4. Update the database credentials in `db.php`.
5. Start Apache and MySQL using Laragon.
6. Open your browser and visit:

```text
http://localhost/NoteShare
```
